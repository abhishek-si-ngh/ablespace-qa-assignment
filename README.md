# AbleSpace QA Assignment

## Application

AbleSpace – IEP Goal Tracking App

## Testing Type

Manual Software Testing / Quality Assurance

## Environment

Staging application:

https://staging.ablespace.io

## Tester

Aarav Mehta

## Testing Scope

This assignment covers:

- Section 2 – Exploratory Testing
- Section 3 – Detailed Test Cases
- Section 4 – Bug Reports
- Section 5 – Compatibility Testing
- Section 6 – Testing Summary

Section 7 – Playwright automation was optional and was not included.

## Testing Approach

Testing was performed using one manually created test account and fictional test data.

The testing focused on:

- Functional behavior
- Input validation
- Workflow navigation
- Data creation and editing
- Session data recording
- Calculation and statistics verification
- Responsive behavior
- Cross-browser compatibility
- Reproducible defects

## Important Notes

- Only one manually created test account was used.
- Fictional test data was used during testing.
- No real user data was used.
- No security or penetration testing was performed.
- No load or performance testing was performed.
- Native mobile application testing was not performed.
- Mobile compatibility observations were performed using the responsive web application at a viewport of 390 × 844.
